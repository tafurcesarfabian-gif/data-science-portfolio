# Proyecto actual — Proyecto 1

## Nombre

`ecommerce-sales-analytics`

## Dataset

Brazilian E-Commerce Public Dataset by Olist.

## Objetivo

Analizar el comportamiento de las ventas de un marketplace para identificar oportunidades de crecimiento, rentabilidad, desempeño de productos, clientes y logística.

## Tablas principales

- customers
- orders

- payments
- products
- sellers
- reviews
